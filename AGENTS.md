# AGENTS.md

## UI/UX Pro Max skill

Use this project-local skill whenever the task involves UI/UX design, interface improvements, landing pages, product pages, marketing pages, responsive layouts, or design-system decisions.

### Working rules
1. Identify the product type and conversion goal before choosing the visual system.
2. Choose a practical layout pattern for the page, then match it with a suitable style family.
3. Keep accessibility in mind: contrast, semantic labels, keyboard focus, and reduced motion.
4. Prefer polished production UI over over-designed mockups.
5. Validate the implementation for responsiveness and usability.

### Design default for this project
- Premium ecommerce storefront
- High contrast but clean premium palette
- Strong product focus and CTA emphasis
- Mobile-friendly product browsing and sticky top navigation
- Trust-building elements like store info, testimonials, and clear checkout flow

### Quality bar
- No broken layouts at common widths: 375px, 768px, 1024px, and 1440px
- No clipped labels or overflowed chips/tags
- Clear interactive states for buttons, links, and filters
- Consistent spacing and typography hierarchy

This skill is intended to guide UI decisions for this project and future front-end work.
